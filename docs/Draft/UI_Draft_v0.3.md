## 1️⃣ パラメータUI（最初にいじれるやつ）

> Q1「まずはタルモンの提案どおりで」

じゃあ **「最初からUIに出すパラメータ」** をこの7つに固定しようと思う：

1. **ANDRO_UNIT_COUNT**
   アンドロ軍団の初期ユニット数

2. **HUMAN_UNIT_COUNT**
   人類軍団の初期ユニット数

3. **HUMAN_TECH_SPEED**
   人類の進化スピード（兵器アンロックの速さ）

4. **ANDRO_ATTACK_MULTIPLIER**
   アンドロ側の攻撃力補正

5. **HUMAN_ATTACK_MULTIPLIER**
   人類側の攻撃力補正

6. **CASSHERN_POWER_MULTIPLIER**
   キャシャーンの強さ倍率

7. **SIMULATION_SPEED**
   シミュレーションの進行速度（ゆっくり〜高速）

これは **ゲーム開始前の設定画面 or サイドパネル** に
スライダー／数値入力で並べるイメージで設計に入るね。

（将校数・小隊サイズ上限・AI性格パラメタは「詳細設定」側に逃がしておく）

## 2️⃣ 小隊表示仕様の反映

> Q2「小隊は、参加人数に比例した大きさのブロック表示でいいよ。」

これ、UI的にかなり分かりやすくて良い👌
既存ルールと統合するとこうなる：

### 基本ルール

* **個人ユニット（小隊に属さない兵や雑魚アンドロ）**

  * 1キャラ＝1ドット or 小さい四角（最小サイズ）

* **小隊ユニット**

  * **所属人数に比例してブロックを大きくする**
  * 例：

    * 〜30人：小さめブロック
    * 〜100人：中くらい
    * 〜500人：でかブロック
      （実際のスケールはUI設計時に調整）

* **色のルール（再確認）**

  * アンドロ軍団：赤
  * 人類軍団：青
  * ブロッケンJr：紫（ボスサイズ）
  * キャシャーン：白（ボスサイズ）

### 階級・小隊との関係

* 小隊ブロックの「中身」は

  * **将 or 佐 or 尉 + 兵たち** という構成
* 表示としては：

  * ブロックの大きさ：人数依存
  * 色：陣営依存（青）
  * 将校の“格”は

    * 将：大きい青ブロック
    * 佐：中サイズ
    * 尉：小サイズ
      みたいに「最大ブロックサイズの上限」で差をつけてもいい。

（ここは後でUIの絵を描きながら微調整だね）

## 4️⃣ 次に詰めたいのは「1tickで何が起こるか？」

要件とUIの土台ができてきたので、
そろそろ **ゲームループ（シミュレーション1ステップの流れ）** を
ざっくり決めておくと、あとで実装フェーズに移りやすい。

タルモン案の 1tick 流れはこんな感じを想定してる：

1. **UI入力の反映**

   * キャシャーンのモード変更（突撃／援護／殲滅）
   * Pause/Resume/Stop/Restart の状態反映

2. **時間の更新**

   * tick + 1
   * 実時間への換算は SIMULATION_SPEED で調整

3. **進化・テック処理**

   * 人類の TechLevel 更新
   * アンロック条件を満たしたら

     * 兵器アンロック
     * UI側へ通知

4. **知覚フェーズ**

   * 各ユニット／小隊が

     * 視界内の敵
     * 視界内の味方
       を把握する（WebGPUに乗せたい処理候補）

5. **AIフェーズ**

   * アンドロ軍団：

     * `SimpleAggressiveAI`（探す→移動→攻撃）
   * 人類：

     * `TacticalHumanAI`（陣形・装備選択・逃げる/近づくなど）
   * キャシャーン：

     * `HeroBehavior`（現在モードに応じた行動決定）

6. **移動フェーズ**

   * 各ユニット／小隊の位置を更新

7. **戦闘フェーズ**

   * 射程内ターゲットへの攻撃処理
   * ダメージ計算（攻撃力・防御力・装備補正・将来的には地形補正など）

8. **死亡処理・除外**

   * HP <= 0 のユニットを死亡扱いに
   * 小隊の人数カウント更新

9. **勝敗判定**

   * アンドロ残数 0 → 人類勝利
   * 人類残数 0 → アンドロ勝利
   * 決着ならステータス更新

10. **描画用スナップショット生成**

* レンダリングレイヤ用に
  「位置＋色＋サイズ」などをまとめて渡す
