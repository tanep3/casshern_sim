# 📝 要件定義書 Draft v0.6（スケール＆ゲーム性反映）

## 1. スケール要件（ユニット数）

* **最終目標スケール**

  * アンドロ軍団：**最大 1,000 体**
  * 人類軍団：**最大 100,000 体**

* この数は **ゲーム開始時／リスタート時のパラメータで設定可能** にする。

  * 例：

    * ANDRO_COUNT = 300
    * HUMAN_COUNT = 8,000
    * など自由に設定し、バランス探索・シミュレーションを行える。

* 実装上は：

  * v0 では小さめから始めるとしても、
    **設計レベルでは 1,000 vs 100,000 を見据えた構造**を前提にする。

---

## 2. ゲーム性の扱い（シミュレータ兼ゲーム）

* 本システムは「**シミュレーションでありつつ、最初から“ゲームシステムとして完成度を目指す”**」。
* 勝敗は

  * **どちらかが全滅した時点で決着**
  * ただし、ユニット数・初期配置・AIによって結果は大きく変動する。
* 人数設定のパラメータ化は

  * **ゲームバランス調整**
  * **シミュレーション条件変更**
    の両方の目的を持つ。

---

## 3. UI・操作（再掲＋補足）

* キャラブロック表示（色・サイズルールは前回通り）
* キャシャーン操作：

  * 画面上のボタンで

    * 「突撃」
    * 「援護」
    * 「殲滅」
  * 初期値：**殲滅モード**
  * 現在モードはステータス表示エリアに常時表示
* 兵器アンロックエリア：

  * 最初空
  * アンロックされた兵器が順次追加表示
  * 同時に通知エリアにメッセージ
* シミュレーション制御：

  * Pause / Resume / Stop / Restart ボタンを用意
